Hilbert's Hotel

A hotel with infinitely many rooms. Every room is occupied. A new guest arrives and, somehow, there's still a bed for them.

One more guest

The rooms are numbered 1, 2, 3, … with no last room. Tonight every room has a guest in it. A traveller walks in and asks for a room.

A finite hotel would have to turn them away. This one doesn't: ask every guest to move from room n to room n + 1. Everyone still has a room, and room 1 is now free. Press the button to watch it happen.

The hotel is full: guest n is in room n, forever.

An infinite bus

Fine, one guest is easy. But now an infinitely long bus pulls up, with passengers B1, B2, B3, …, and they all want rooms.

Shifting everyone by one won't work, since there are infinitely many newcomers. Instead, move the guest in room n to room 2n. Everyone is housed again, and now all the odd rooms are empty. Passenger Bj takes room 2j − 1. Try the second button above.

What's really going on. We keep saying "infinity plus one" and "infinity plus infinity", but there's no number being added. The honest statement is about matching things up. Two collections are the same size if you can pair every item in one with exactly one item in the other. The hotel tricks are just pairings: n ↔ n + 1 and n ↔ 2n.

Infinitely many buses

Now the hotel is full and infinitely many buses arrive, each carrying infinitely many passengers. Surely that's too much?

It isn't. Lay the passengers out in a grid: bus 1's seats along the first row, bus 2's along the second, and so on. Then walk through the grid diagonal by diagonal, handing out room numbers in the order you meet people. Every passenger is reached after finitely many steps, so every passenger gets a room.

Hand out rooms along the diagonals

Switch to Fractions to see the same idea applied to the rational numbers. Row p, column q is the fraction p/q. Fractions like 2/2 or 2/4 repeat a value already seen (as 1/1 and 1/2), so we skip them. Every positive fraction ends up with a number. Interleave positive, negative and zero, and every rational number can be put in one list.

That is surprising, because the fractions are dense: between any two of them there are infinitely many more. Yet there are exactly as many fractions as whole numbers. Sets that can be listed like this are called countable, and the size of the whole numbers is written ℵ₀ ("aleph-null").

Go deeper: the definitions

Two sets A and B have the same cardinality if there is a bijection f : A → B, that is, a function that is one-to-one (no two inputs share an output) and onto (every element of B is hit). A set is countably infinite if it has the same cardinality as ℕ = {1, 2, 3, …}.

Facts you can prove with explicit bijections:

  • ℕ ↔ ℕ \ {1} via n ↦ n + 1. More generally, an infinite set can match a proper piece of itself. (Dedekind took this as the definition of an infinite set.)
  • ℕ ↔ 2ℕ via n ↦ 2n.
  • ℕ ↔ ℤ by listing 0, 1, −1, 2, −2, ….
  • ℕ × ℕ ↔ ℕ via the Cantor pairing function π(i, j) = (i + j − 2)(i + j − 1)/2 + i. The grid demo above does the same thing, except it zig-zags along alternate diagonals instead of always walking the same direction.
  • ℚ is countable: map p/q in lowest terms to the pair (p, q), which gives an injection into ℕ × ℕ, and any subset of a countable set is countable.

Arithmetic of the cardinal: ℵ₀ + 1 = ℵ₀, ℵ₀ + ℵ₀ = ℵ₀, ℵ₀ · ℵ₀ = ℵ₀. Every "paradox" on this page is one of these equalities.

So is every infinity the same?

If all of these infinite sets are the same size, maybe "infinity" is just one thing after all. It isn't, and the next page shows the argument that proved it.
