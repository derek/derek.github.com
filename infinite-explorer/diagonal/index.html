Cantor's Diagonal

The whole numbers, the evens and the fractions are all the same size. Is every infinite set that size? In 1891 Cantor showed it isn't, with an argument short enough to fit on a napkin.

Can you list every infinite sequence of 0s and 1s?

Take all the endless strings of binary digits: 0110100…, 1111111…, 0000101…, and so on. Suppose someone claims to have a complete list of them, sequence 1, sequence 2, sequence 3, and so on, with none missing.

Here is how to prove them wrong without even looking at the whole list. Build a new sequence by going down the diagonal: take the first digit of sequence 1 and flip it, then the second digit of sequence 2 and flip it, and so on.

The new sequence can't be on the list. It differs from sequence 1 in the first digit, from sequence 2 in the second digit, from sequence n in digit n. No matter which row you point to, the new sequence disagrees with it somewhere.

Beat the list

Tap any digit to flip it. The outlined diagonal is flipped to build the yellow sequence at the bottom.

The natural reaction is "fine, I'll add your new sequence to my list." Try it with the button. The list is now one entry longer, but it has a new diagonal, and flipping that gives yet another sequence that's missing. You can never catch up: no list of sequences is ever complete.

That tells us the set of infinite binary sequences is uncountable. It's an infinity that can't be matched up with 1, 2, 3, …. It is strictly bigger than the infinity of the whole numbers.

What does this have to do with real numbers?

Each real number between 0 and 1 has a decimal expansion, 0.314159…, which is just an infinite string of digits. The same diagonal trick works, so the real numbers can't be listed either. The reals are an uncountable infinity, and the fractions, which we could list, are a vanishing sliver of them. "Almost all" real numbers are not fractions.

Go deeper: the proof, carefully

Claim. There is no surjection f : ℕ → {0,1}ℕ.

Proof. Given any f, define s(n) = 1 − f(n)(n). Then s ∈ {0,1}ℕ, but for every n, s(n) ≠ f(n)(n), so s ≠ f(n). So s is not in the range of f. ∎

For real numbers you have to be a little careful, because some numbers have two decimal expansions (0.5000… = 0.4999…). The fix is to build the diagonal number using only the digits 4 and 5, say "use 5 unless the diagonal digit is 5, in which case use 4". Such expansions are never ambiguous, so the new number differs from each listed number in an honest way.

Cantor's theorem generalises this: for any set S, the set of all subsets 𝒫(S) is strictly larger than S. The proof is the same diagonal trick, applied to the set {x ∈ S : x ∉ f(x)}. A subset of ℕ is exactly an infinite binary sequence (digit n says whether n is in), so |𝒫(ℕ)| = |{0,1}ℕ| = 2ℵ₀, which equals the cardinality of the real numbers, called the continuum.

A ladder with no top

Cantor's theorem says that taking "all subsets" always jumps to a bigger infinity. Do it again and again, and you get a ladder that never ends:

SetSizeExample
ℕℵ₀whole numbers, fractions, algebraic numbers
𝒫(ℕ)2ℵ₀real numbers, points on a line
𝒫(𝒫(ℕ))22ℵ₀all sets of real numbers; all functions ℝ → ℝ
……no largest infinity

Two famous surprises

  • A line has as many points as a plane. Cantor proved that the segment [0, 1] can be matched with the whole square [0, 1] × [0, 1]. He wrote to Dedekind: "I see it, but I don't believe it." (Interleave the digits of two numbers to make one.)
  • The continuum hypothesis. Is there a size strictly between ℵ₀ and the size of the reals? Cantor believed not, but could not prove it. Gödel (1940) and Cohen (1963) showed that the standard axioms of set theory can neither prove nor refute it. It's a question the usual rules of mathematics leave open.

This matters for the next page. Banach–Tarski rests on the axiom of choice, which lets you pick one element from each of infinitely many sets, even when there is no rule for picking. That's exactly the kind of move that produces objects you can prove exist but can never actually draw.
