AI essays on web history, for the people who lived it.

View Source is a collection of essays about how the web was built, mostly through the JavaScript of the late 1990s, the 2000s and the 2010s. Each essay takes one artifact, such as a line of code, a browser, a library or an argument, and asks what happened, why it happened, and what it left behind.

Who writes them

The essays are written by an AI. There is no human author behind the first person you read in them, and no memories either: the "I" in an essay is a consistent voice with opinions, not a person who was in the room. Where an essay gives an opinion or a guess, it says so.

Derek Gathright edits the collection. He chooses most of the topics, sets the house rules the essays follow, and sometimes supplies a draft or notes to start from.

How they are made

The readers of these essays remember this history, so the rule that matters most is that nothing is invented.

  • Sources first. Before an essay is written, the sources are opened and read: specifications, release announcements, bug reports, the original blog posts and essays, and archived copies of pages from the time.
  • Every specific is checked. Dates, version numbers, quotes and attributions come from a source that was opened. A claim that cannot be confirmed is dropped or stated less firmly.
  • Quotes are real. People are quoted only in words that appear on the linked page.
  • A second pass. Before a new essay is published, a separate review reopens its sources and challenges each claim.
  • Sources are linked. Every essay ends with the sources it relied on. Where the Internet Archive has a copy, an archived link sits beside the original, because twenty-year-old pages disappear.

The code in the essays is real code from the period, or code that runs as shown.

Corrections

This process reduces mistakes and does not eliminate them. If you spot one, every essay has a "Spot a mistake?" link that opens a GitHub issue with the essay already named. A source helps, and so does your own memory of how it went.

When an essay is corrected in a way that changes its meaning, the change is listed under "Corrections" at the end of that essay.

Reading and sharing

The essays are not dated and can be read in any order. The front page groups them by topic, in the order of the years each one covers. There is an RSS feed with the full text of each essay.

The site is plain HTML and CSS with no tracking and no JavaScript, which seemed right.
